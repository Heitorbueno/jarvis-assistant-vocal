Provedores de IA

As chaves ficam somente no config.yaml deste PC e nunca são devolvidas ao navegador. Testar conexão lista os modelos da sua conta (sem custo). OpenAI, Anthropic e Ollama podem ser o cérebro do Jarvis; os demais ficam salvos para conectores.

Ordem de fallback

Se o modelo principal falhar (erro, sem crédito, fora do ar), o Jarvis tenta estes, em ordem. No modo local, só entradas Ollama são usadas. Adicione a partir dos favoritos de cada provedor.

Como expor (escolha um)

Tailscale Serve (recomendado, privado na sua tailnet, HTTPS automático):

tailscale serve --bg 8790
Host = o nome mostrado por tailscale serve status (…ts.net). Para internet pública: tailscale funnel --bg 8790.

Cloudflare Tunnel (domínio próprio):

cloudflared tunnel --url http://127.0.0.1:8790
Ou túnel nomeado apontando o hostname para http://127.0.0.1:8790. Host = seu hostname.

IP público: use um proxy HTTPS no PC (ex.: Caddy reverse_proxy 127.0.0.1:8790) com o seu domínio. Não exponha a porta 8790 sem TLS.

Instalar como app (PWA): abra o endereço HTTPS → Android/Chrome/Edge: “Instalar app”; iPhone/iPad: Safari → Compartilhar → “Adicionar à Tela de Início”.
